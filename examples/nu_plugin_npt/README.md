# NPT demo plugin

This plugin is a demo and test for nu-plugin package (`npt` stands for `Nu Plugin Test`).

It implements various subcommands which either demonstrate some use case/feature or help to debug them.

## Commands

| name   | description |
|--------|-------------|
| ac     | autocomplete flags and arguments |
| echo   | returns the input as output |
| engine | An example how to call the plugin engine APIs |
| error  | returns error, ie command that always fails |
| what   | returns information about how the plugin sees the input |
